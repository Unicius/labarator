# Проект «Прочность балки на изгиб» (Вариант 8)

Интерактивная консольная программа для проведения поверочного расчёта прочности балок различных сечений на изгиб.

## Описание

Программа выполняет расчет момента сопротивления сечения $W$, максимального изгибающего напряжения $\sigma$ и определяет класс запаса прочности балки.

### Типы сечений:
1. **Прямоугольное:** $W = \frac{b \cdot h^2}{6}$
2. **Круглое:** $W = \frac{\pi \cdot d^3}{32}$
3. **Двутавр:** $W = \frac{h^3}{12}$ (упрощенная модель)

### Диапазоны входных данных:
- Размеры сечения: `10..1000` мм
- Изгибающий момент $M$: `0.1..500` кН·м
- Допускаемое напряжение $[\sigma]$: `50..400` МПа
